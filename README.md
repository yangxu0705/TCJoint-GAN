# TCJoint-GAN
This project proposes an innovative intelligent joint generation framework for Tri-branch Convergent Joint by Generative Adversarial Network named as TCJoint-GAN. Compared with existing joint design methods, this study integrates topology optimization with targeted data augmentation techniques to synthesize a diversified, high-fidelity training dataset tailored specifically for spatial joints. Furthermore, a sophisticated reverse engineering workflow is developed to seamlessly translate voxelized representations into manufacturable solid models while preserving geometric integrity, thereby effectively addressing the persistent challenges of dataset construction and geometric reconstruction in intelligent joint design.
